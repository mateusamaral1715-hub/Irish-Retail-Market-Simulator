# 🇮🇪 Irish Retail Market Simulator: End-to-End Data Project

This repository showcases a complete Data Analytics workflow, from automated data generation to strategic business visualization. I developed this project to simulate a high-volume retail environment in Ireland, focusing on scalability and regional performance analysis.

## 🚀 Project Highlights
* **Scale:** Engineered a robust dataset with **50,000+ records** of synthetic sales data.
* **Tech Stack:** Python (Data Generation), CSV (Storage), and Power BI (Analytics & UX).
* **Business Focus:** Modeled specifically for the Irish market, including regional trends (Dublin, Cork, Galway, Limerick) and local economic indicators.

---

## 🐍 Part 1: Data Engineering (Python)
To move beyond static spreadsheets, I built a custom **Python Synthetic Data Engine**.

* **The Code:** You can find the script in `generate_irish_sales.py`. It uses libraries like Pandas and Numpy to create realistic distributions of prices, dates, and customer demographics.

## 📊 Part 2: Business Intelligence (Power BI)
The generated data was then transformed into a professional-grade executive dashboard:

* **Advanced Modeling:** Implemented a Star Schema to handle 50k+ rows efficiently.
* **Strategic DAX:** Created complex measures for YTD (Year-to-Date) growth, Regional Market Penetration, and Sales Forecasting.
* **Localization:** The dashboard is fully localized for the Irish market, utilizing EUR (€) and regional hierarchies.
